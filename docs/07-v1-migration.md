# V1에서 V2로 이전
이 ZIP은 기존 배포된 초기 V1(AX-00 READY, 나머지 PENDING)을 기준으로 만들었다. V1의 실질 진행 결과가 확인되지 않았으므로 V2 초기 상태도 AX-00 READY다. 기존 사용자의 진행 상태를 삭제하거나 덮어쓰지 않는다.
- 신규 레포에는 그대로 사용한다.
- 이미 레포에서 진행 중이면 먼저 기존 브랜치/상태/records/실제 대상 SHA를 확인하고 백업 또는 별도 브랜치를 만든다. V2 파일을 비교해 필요한 변경만 적용한다. 원본 기록은 보존한다. AX-00~10 식별자는 동일하므로 기존 검증 근거를 재사용할 수 있으나 V2 추가 기준을 검토하고 재검증 필요 항목을 기록한다.
- 진행 상태가 달라졌다면 자동 초기화하지 않는다. 순서 변경 때문에 기존 완료 단계가 뒤에 존재할 수 있다. V2 상태 모델과 충돌하는 경우 단계별 기존 증거를 보존하고 사용자 승인된 마이그레이션 보고서를 작성한 후 실제 기준 충족 여부에 따라 상태를 재구성한다. 이전 증거를 버리거나 실제 하지 않은 검증을 PASS로 채우지 않는다. 이 ZIP은 자동 상태 마이그레이션을 제공하지 않는다.
