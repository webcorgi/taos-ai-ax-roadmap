# AX-10 — pgvector: 벡터 저장 기술 선택 (실습 필수 · 운영 채택 조건부)

Qdrant가 이미 작동하므로 무조건 이전하지 않는다. 업무에서 PostgreSQL 통합이 필요할 때 채택 여부를 판단한다.

## 실행
1. 공식 pgvector와 PostgreSQL 버전/확장 지원, 라이선스, 독립 데이터베이스/백업 정책 확인. 운영 PostgreSQL에 확장 설치 금지. 실익 부족 시에도 독립 합성 데이터 비교 실습을 수행한다.
2. 동일한 승인 코퍼스/청크/임베딩 버전/차원/유사도/프로젝트 필터/질문 세트로 Qdrant 기준과 비교. PostgreSQL 별도 DB·격리 포트와 vector 확장 사용. exact 및 필요한 approximate index 비교. 문서 갱신/삭제 및 권한 필터를 검증.
3. Recall@5, p50/p95, 색인·갱신 시간, 자원/저장량, 백업/복구, 운영 복잡도 기록. 의미 검색과 하이브리드 검색을 섞어 비교하지 않는다. 차이가 있는 경우 조건 명시.
4. 운영 이전 이점이 실제로 확인되지 않으면 Qdrant 유지. 이전한다면 별도 마이그레이션·데이터 무결성·검색 회귀·롤백 설계 승인 후 진행.

## 완료 기준
- [ ] 비교 필요성 및 격리 환경 확보
- [ ] 고정 질문과 데이터로 품질·성능·운영 비교
- [ ] 현행 유지/선택 사유 기록, 운영 데이터 변경 없음 확인

지속 성과: 실제 운영 선택과 비용·관리 개선에 근거를 제공. 비교 실험 자체는 역량 증빙이며 업무 효과와 분리한다.
