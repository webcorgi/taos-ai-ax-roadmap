# AX-09 — vLLM: 추론 성능 비교 (조건부)

Ollama는 이미 사용 중. 현재 하드웨어 및 동시 요청 수가 vLLM 도입 필요성을 만드는지 확인하는 것이 목표다.

## 실행
1. 실제 CPU 아키텍처/RAM/GPU/VRAM/드라이버, 현재 vLLM 설치 문서 및 모델 호환성 확인. 기존 서비스 여유 자원과 운영 승인. CPU 가능 여부와 실익을 구분하고 적합한 장비가 없으면 사용자 승인으로 DEFERRED.
2. 별도 서버/컨테이너, 포트·모델 파일·자원 한도 격리. Ollama 중단·교체 없이 승인된 모델 후보와 동일 평가 문서/질문 준비. 모델·양자화·context·max output·sampling·warmup 조건을 가능한 한 맞추고 불일치 명시.
3. 동시성 1 및 승인된 부하 수준(예: 2/4) 비교. TTFT/전체 시간 p50·p95, 생성 tokens/s, 실제 출력 수, throughput, 오류/timeout, CPU/RAM/GPU/VRAM을 기록. 같은 질문의 품질·출처·보류 동작도 확인. OOM, 취소, 재시작 검사.
4. 성능과 품질, 비용/운영 부담을 함께 판단. 더 나은 결과가 없으면 현행 유지. 운영 전환은 별도 승인·롤백 후 진행.

## 완료 기준
- [ ] 실제 호환성과 자원 확인 또는 승인된 보류
- [ ] 동일/명시된 조건 비교 및 실패/품질 기록
- [ ] 현행 유지 또는 채택 근거와 롤백 절차

지속 성과: 실제 동시 수요가 있을 때 모델 추론 처리량/지연/비용 개선. 단순 설치나 모델 다운로드는 성과가 아니다.
