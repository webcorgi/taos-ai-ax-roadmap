# AX-19 — MLflow·모델 생명주기
목표: AX-17/18 모델 실험을 재현 가능한 관리 체계로 전환한다. https://mlflow.org/docs/latest/.
## 실행
1. 독립 MLflow 저장소를 구성하고 민감 원문 대신 데이터 스냅샷 식별자·hash·split·환경·모델 버전·seed·metric을 기록. artifact 저장 경로/권한/보존 정책 확인.
2. 두 모델/설정 실험을 기록하고 동일 평가 결과를 재현한다. 등록·검증 후보·승격/원복 과정을 실제 합성 모델로 시험. 자동 승격 금지 기본. 데이터/모델 drift 개념 및 주기 평가, 실패 보고를 설계한다.
3. LLM 서비스 추적은 Langfuse, ML 학습/실험 관리는 MLflow로 역할 분리. 학습 파이프라인 자동화/registry/Kubeflow 개념과 필요 시 비교를 기록하되 도구 중복 설치 금지.
## 완료
- [ ] 실험 2개 이상 및 재현/버전/복원 시험
- [ ] 모델 품질 저하 검출과 운영 채택 기준 문서화
