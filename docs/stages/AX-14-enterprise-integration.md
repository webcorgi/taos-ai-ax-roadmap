# AX-14 — 기업 시스템 연동·인증·권한
목표: 기업 내부 시스템과 AI의 연결을 단순 API 호출 이상으로 구현한다. ERP/MES/PLM은 실제 권한을 확인하기 전에는 합성 API 사용. TAOS 운영 DB/장비 제어 금지.
## 실행
1. 현업 업무 한 가지를 인터뷰/승인받아 입력·판단 기준·담당자·결과·권한·예외·수동 기준 시간을 정의한다. 실제 ERP/MES/PLM 연동 권한 없으면 모의 REST API와 표준 데이터 모델을 만들고 실제 연동이 아님을 표시.
2. 격리된 RAG/업무 Agent에 인증(SSO/OIDC 또는 사내 인증 방식; 합성 IdP 가능), 역할별 RBAC, 사용자/프로젝트별 문서 필터와 서버 측 도구 허용 범위 적용. 토큰 검증, 세션·감사·최소 권한, API gateway 개념 학습. 모델이 보낸 역할값을 신뢰하지 않는다.
3. SQL/NoSQL 정형 조회는 파라미터 제한·읽기 전용 API·시간/건수 상한 적용. 임의 SQL·shell·URL 금지. 도구 결과는 구조화하고 정확한 계산은 서버 수행. 권한이 없는 문서는 검색·캐시·인용·다운로드·추적에서도 차단한다.
4. 사용자 A/B, 허용/거부, 토큰 만료/위조, 간접 공격, 데이터 소스 장애, API schema 변경, 감사 로그 확인. 사내 RAG 외부 공개는 실제 인증·인프라 보안 승인 이후만.

- [ ] 현업 요구 및 사용자 피드백/업무 효과 측정 계획 기록
