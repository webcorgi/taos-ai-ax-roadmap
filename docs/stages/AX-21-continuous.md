# AX-21 — 지속 운영과 기술 변화 관찰
목표: 단기 학습을 일회성 결과로 끝내지 않는다. 이 단계 완료는 **첫 반복 검증 체계 구축/실행**이며 학습 종료나 장기 성과 달성 의미가 아니다.
## 실행
1. 승인된 운영/파일럿의 반복 업무별 누적 지표(처리량, 성공/보류, 사람 개입, 실제 소요 시간, 비용/지연, 평가·보안 실패, 재발)를 기록할 위치와 담당자 정의. 단순 기술 실험과 실제 사용을 별도 집계.
2. 첫 주간 지표 리뷰와 월간 독립 평가/보안 회귀의 재현 가능한 절차를 만든다. 가능한 첫 실행 실시. 데이터 부족은 미측정. 승인 없는 예약 작업 생성/외부 공유 금지.
3. 월간 모델·도구 릴리스, 보안 공지, MCP/A2A/멀티모달/Agent runtime/오픈 모델 변화 확인. 분기별 채용 요구·기술 선택·기업 운영 문제를 재검토하고 필요성 있는 소규모 비교 실험을 진행. 지속적으로 새로운 도구를 운영 설치하지 않는다.
4. 채용용 근거를 업데이트하고 기술 면접 연습, 현재 공고와 경력·학위·지역·연봉 조건 대조. 취업 보장 금지. 이후에도 `records/continuous/`에 날짜별 비식별 기록을 누적한다.
## 완료
- [ ] 첫 주간 검토 및 평가 절차 실측 증빙, 다음 리뷰 날짜/담당자/승인 범위 기록
- [ ] 장기 추적 항목과 변경 판단 기준 명확화. 지속 실행 여부는 실제 기록으로 검증
