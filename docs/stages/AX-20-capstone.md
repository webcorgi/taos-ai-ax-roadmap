# AX-20 — 종합 AX 실무 프로젝트·면접 준비
목표: 승인된 반복 업무 1개에 실제 적용하여 채용용 증거를 확보한다. 새 거대 플랫폼 강제 구축 금지. 기존 RAG + 읽기 도구 + 보고 흐름 활용.
## 실행
1. 현업 담당자와 실제 문제, 사용 주기, 수동 기준 시간·품질·분모·사람 승인/위임 범위를 확정. 개인정보 및 회사 공개 승인 확인. 파일럿 범위와 종료 조건 합의.
2. 선택 기술만 통합: 권한 기반 RAG, 구조화 출력·Tool Calling/MCP, 필요 시 Agent 상태, Langfuse/평가/보안 게이트. 실제 업무 데이터 접근이 없으면 합성 파일럿과 실제 운영 준비를 구분. 실패·재시도·취소·복구 및 사용자 화면까지 E2E.
3. 동일 업무 전후 실제 시간·결과 일치·실패/사람 개입률을 기록. 파일럿 최소 3회 목표, 실제 사용 및 담당자 승인 없는 결과는 운영 성과로 금지. 누적 월간 지표는 AX-21에서 계속 관리.
4. 면접용 1페이지 케이스(전후 아이콘 흐름도, 기준, 위임 범위, 검증, 한계, 누적 지표) + 익명화 설계/테스트/코드 일부 + 5분 시연. 회사 정보 공개는 승인 이후. AI 없이 핵심 Python/API/SQL 디버깅, 설계 비교, 보안·장애 시나리오 설명을 직접 수행. AI 지원 여부와 실제 수행 결과를 구분.
## 완료
- [ ] 실제 파일럿 또는 명확히 구분된 격리 재현 및 승인/미승인 범위
- [ ] 검증 수치·실행 증거·시연 자료·면접 모의 검증, 미충족 채용 조건 기록

## V3 낯선 고객 종합 과제
기존 TAOS 시스템 복제 대신 평가자가 새로운 합성 기업 데이터·API·역할·예산·실패 조건을 제시한다. 사용자는 요구사항 확인, As-Is/To-Be, 비AI 대안, 설계, 독립 핵심 수정과 장애 진단, 권한 및 승인 테스트, 인수 기준, ROI·확산 계획 및 경영진 1페이지 제안까지 수행한다. 평가용 실패 조건은 풀이 전 공개하지 않는다. 기존 실제 승인 파일럿 조건도 유지하며 모의 과제는 실제 고객 성과로 표시하지 않는다. 외부 리뷰 가능 시 요청하되 불가하면 미확인 기록. `docs/08-v3-depth-and-ax.md` 기준 적용.
