# AX-13 — 문서 ETL·Docling·OCR·VLM
목표: 기술 매뉴얼, 연구 문서의 표·스캔을 근거가 보존된 RAG 입력으로 변환한다. https://docling.ai/ , https://www.paddleocr.ai/ , https://pandas.pydata.org/docs/.
## 실행
1. 승인된 합성/비식별 PDF, 스캔 이미지, 표·다단 레이아웃 등 소규모 평가 세트(목표 10~20페이지)를 만들고 기대 텍스트·표 셀·페이지/좌표를 사람이 고정한다. HWP/DOCX/CAD는 실제 요구와 지원 확인 후 별도 샘플로만; 무조건 파싱 가능하다고 주장 금지.
2. 기존 pypdf와 Docling, 필요 시 로컬 OCR/PaddleOCR 및 승인 VLM 하나를 비교한다. 문서 인코딩·정제·중복/버전·결측·출처/페이지·표 구조를 관리한다. 원본 읽기 전용, 임시 저장/로그 민감정보 제거.
3. Pandas/Polars 중 하나로 구조화 데이터 정제와 검증, 소규모 증분 ETL(입력 해시·오류·재개·중복 방지) 구현. Airflow/Prefect/Dagster의 역할을 개념 비교하되 단순 배치면 도입 불필요.
4. 셀/필드/문자 일치, 누락·실패, 추출 시간·메모리 및 RAG 출처 일치 측정. 표 추출과 VLM 해석 오류를 구분. 실패 원본은 보류하고 원문 확인 경로 제공.

- [ ] 선택 기준·정량 비교·운영 도입 여부 기록
