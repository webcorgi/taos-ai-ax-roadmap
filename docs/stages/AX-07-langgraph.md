# AX-07 — LangGraph: 승인·중단·재개되는 AI 업무 흐름

대상: AX-06 보고 업무의 복합 검토 부분 또는 승인된 별도 업무. 이미 정상 동작하는 Sentry 자동 대응 워커를 교체하지 않는다. n8n과 LangGraph가 같은 스케줄/승인 상태를 이중 관리하지 않도록 분리한다.

## 실행
1. 공식 LangGraph 버전, Python 호환성과 checkpointer/interrupt/durable execution 문서 검토. 상태 스키마와 상태 전이 정의. 격리 체크포인트 저장소 사용.
2. 자료 수집 → 검증 → 초안 → 사람 승인 interrupt → 수정 요청/보류/승인 → 내부 결과 저장. 모델은 초안·요약, 서버는 검증·권한·실행 관리. 실제 발송/운영 제어 금지.
3. `thread_id`/업무 id와 재실행 키, 승인자와 상태 버전, 만료, 재시도/루프 상한. 체크포인트에 원문·비밀 저장 최소화. 사람의 승인 값을 서버에서 인증/검증. 재개 시 부작용이 있는 노드 중복 실행 방지.
4. 정상 승인·거절·수정 루프·만료·중단/프로세스 재시작·중복 재개·모델 실패·권한 오류 테스트. 테스트 중 승인되지 않은 저장/외부 호출 여부 확인. 기존 n8n과 통합할 경우 단일 상태 소유자 명시.

## 완료 기준
- [ ] 상태 그래프와 승인 경계가 구현·문서화됨
- [ ] 재시작 전후 상태 일치, 중복 부작용 없음, 미승인 경로 차단
- [ ] 정상·실패·보류·재개 결과 및 재현 방법 기록
- [ ] n8n 단순 흐름 대비 추가 복잡성이 필요한 이유와 유지/미도입 결정 기록

지속 성과: 사람 승인 대기, 재개 성공률, 실패 복구, 중복 처리율. 필요하지 않은 에이전트 루프는 운영에 배포하지 않는다.
